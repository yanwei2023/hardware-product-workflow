# 公司受控文档模板

## 1. 基本信息

| 字段 | 内容 |
|---|---|
| 项目名称 | 由项目立项基线注入 |
| 产品名称 | 由项目立项基线注入 |
| 文档代码 | 由项目文档要求注入 |
| 模板版本 | V1.0 |
| 当前状态 | Agent 草稿，待人员审核 |

## 2. 目的与范围

说明本文档解决的问题、适用范围和明确排除的范围。

## 3. 输入依据

列出使用的批准基线、上游文档版本、法规标准、原始数据和其他证据。

## 4. 正文

Agent 按当前文档类型、项目约束和审核要求组织专业内容。

## 5. 证据与引用

列出可复核的来源、文件、测试记录、数据集及其版本。

## 6. 风险与未决问题

列出假设、风险、冲突、缺失信息和需要人员决策的事项。

## 7. 审核结论

记录审核人、决定、意见、条件和关闭证据。
